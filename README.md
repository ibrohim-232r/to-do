# Taskly — список дел (vanilla JS + Vercel serverless)

Возможности: регистрация/вход, синхронизация между устройствами, приоритеты, сроки, теги,
подзадачи, повторяющиеся задачи, drag-and-drop, поиск, фильтры, сортировка, прогресс,
светлая/тёмная тема, экспорт/импорт JSON, гостевой режим (localStorage). Горячие клавиши: `/` поиск, `n` новая задача.
В поле добавления: `#тег`, `!` / `!!` / `!!!` (приоритет), `сегодня` / `завтра`.

## Деплой на Vercel
1. Залей папку в GitHub-репозиторий и импортируй его в Vercel (Framework Preset: Other). Либо `npx vercel` из этой папки.
2. В проекте: Storage → Create → Upstash Redis (Marketplace). Переменные подключатся сами.
3. Settings → Environment Variables → добавь `AUTH_SECRET` (любая длинная случайная строка, 32+ символа).
4. Redeploy.

## Локально
- Только фронт, без аккаунтов: `npx serve public`, режим «Продолжить без аккаунта».
- С бэкендом: `vercel link && vercel env pull && vercel dev`.

## Структура
- `public/` — index.html, style.css, app.js
- `api/auth.js` — регистрация и вход (scrypt + подписанный токен, без зависимостей)
- `api/tasks.js` — загрузка и сохранение задач пользователя
- `api/_lib.js` — Redis по REST и работа с токеном

## Установка как приложение (PWA)
- Android / Chrome / Edge на компьютере: кнопка «Установить» в шапке приложения или значок установки в адресной строке.
- iPhone (Safari): «Поделиться» → «На экран “Домой”».
- После первого открытия интерфейс работает офлайн; изменения синхронизируются, когда появится сеть.
- Изменил файлы в `public/`? Увеличь версию кеша (`taskly-v1` → `taskly-v2`) в `public/sw.js`.
